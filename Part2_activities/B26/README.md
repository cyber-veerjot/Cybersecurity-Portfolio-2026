## B26 – Helping Another Student Understand a Cybersecurity Concept
I assisted another student in understanding the cybersecurity concept of a honeypot. The learner was unsure of what a honeypot was and how it works in real-world cybersecurity. I stated that a honeypot is a fictitious computer system or service meant to entice attackers so that security teams may securely monitor and analyse malicious activities.
I provided a basic example of a bogus SSH server with weak login credentials to demonstrate how attackers could attempt to breach the system while security teams record IP addresses, commands, malware uploads, and login attempts. I also mentioned that honeypots should appear realistic so that attackers feel they are legitimate systems.
This activity improved my own understanding of:
- Honeypots and threat intelligence
- How organisations detect attacker behaviour
- Real-world defensive cybersecurity techniques
- Explaining technical concepts in simple language
