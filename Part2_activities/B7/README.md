## B7 – Participation in a Cybersecurity Club Activity
### Description:
I went to the University Computer Club's (UCC) cybersecurity tech presentation, "Into The Cuckoo's Egg," which was given by Mark Tearle, as part of this assignment. One of the first and best-known cyber intrusion investigations related to Lawrence Berkeley National Laboratory in the early internet period was covered in the session. The presentation described how a little 75-cent accounting error revealed unauthorised access to computer systems, which in turn revealed a significant cyber espionage incident.
### Topics Covered:
During the activity, several cybersecurity concepts were discussed, including:
- Open-Source Intelligence (OSINT)
- Unix system accounting and log analysis
- Intrusion detection and attacker tracing
- Remote network access and system monitoring
- Password files and compromised accounts
- Session logging and unusual account activity
- Early cyber espionage investigations
- Network intrusion investigation techniques
The speaker described how investigators tracked suspicious behaviour across systems and identified attacker activity by analysing Unix accounting data and session logs.
### What I Learned:
- How little inconsistencies in log data or accounting might highlight significant security events
- The significance of keeping an eye on user behavior and system logs
- How technical evidence and OSINT are integrated during investigations
- Why account management and password security are essential
- How early cyberattacks were carried out using hacked accounts and remote connections
I gained a better understanding of actual cybersecurity investigations and how defenders use evidence analysis to track down attackers and address events thanks to this exercise.
### Analysis:
This exercise illustrated the usefulness of log analysis, OSINT, and system monitoring in cybersecurity investigations. It emphasised the significance of evidence gathering, intrusion detection, and incident response in safeguarding computer systems and demonstrated how seemingly insignificant anomalies can reveal serious threats.
