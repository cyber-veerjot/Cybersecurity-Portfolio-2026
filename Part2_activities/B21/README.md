## B21 - Design and implement a cybersecurity learning activity
### Description:
I used HTML, CSS, and JavaScript to create and deploy an interactive cybersecurity learning exercise. In order to help users better comprehend common cybersecurity ideas and online safety measures, the activity was designed as a browser-based quiz.
### Implementation:
The educational exercise was developed as an interactive multiple-choice test that doesn't require installation and launches straight into a web browser. After completing the test, users earn a final score based on their responses to cybersecurity-related questions.
The quiz included cybersecurity topics such as:
- phishing attacks,
- ransomware,
- multi-factor authentication (MFA),
- password security,
- encryption,
- suspicious links,
- and safe online behaviour.
JavaScript was used for quiz logic and score computation, HTML was used for structure, and CSS was used for styling.
### Design Principles:
* Interactive learning through quizzes
* Immediate feedback through score calculation
* Simple and beginner-friendly interface
* Focus on practical cybersecurity awareness
### How to Use:
In any web browser, open the cyber_quiz.html file. To find out their ultimate score, users can complete the quiz by answering the multiple-choice questions.
### File:
cyber_quiz.html — Interactive cybersecurity awareness quiz
### Analysis:
This exercise illustrated how cybersecurity knowledge and engagement may be raised through interactive learning tools. Users were encouraged to adopt defensive cybersecurity principles and identify typical cyberthreats in real-world situations.
